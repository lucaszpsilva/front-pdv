# Front PDV (DEMO)

Este repositório contém a versão demonstrativa (front-end) de um sistema de Ponto de Venda (PDV) híbrido e Offline First.

## Tecnologias
- React
- TypeScript
- Tauri (Desktop)
- SQLite (Local)

## Aviso
Esta é apenas a interface de demonstração. O backend completo e a lógica de sincronização offline estão em desenvolvimento em um repositório privado.
